# Suit Doc 🧥

**Suit Doc** es una app Android de documentos, **100% offline**, en **español e inglés**.
Editor rich-text por bloques con exportación a TXT / Markdown / HTML / PDF / DOCX / RTF,
cámara + OCR en el dispositivo, «Imágenes → PDF», herramientas PDF (unir/dividir/comprimir/editar),
corrector ortográfico en español, firma con el dedo, IA local offline y temas claro/oscuro.

**Suit Doc** is a **100% offline** Android document app in **Spanish and English**.
Block-based rich-text editor with export to TXT / Markdown / HTML / PDF / DOCX / RTF,
on-device camera + OCR, "Images → PDF", PDF tools (merge/split/compress/edit),
Spanish spell checker, finger signature, local offline AI, and light/dark themes.
